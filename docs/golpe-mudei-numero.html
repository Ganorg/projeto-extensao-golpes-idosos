Golpe do "Oi, mudei de número"

← Voltar ao início

Como funciona

Chega uma mensagem no WhatsApp de um número desconhecido dizendo ser um filho, neto ou amigo: "Oi, tudo bem? Troquei de celular, salva esse número novo." A conversa é simpática. Pouco depois vem o pedido: "preciso pagar uma conta agora e meu aplicativo do banco está com problema, você faz um PIX pra mim?"

Às vezes a foto do perfil é a foto real do parente, copiada das redes sociais.

Como se proteger

  • Ligue para o número antigo do parente. Se ele atender, o outro é golpe.
  • Faça uma chamada de voz ou vídeo para o número novo antes de qualquer coisa. Golpista costuma inventar desculpa para não atender.
  • Pergunte algo que só a pessoa saberia responder.
  • Nunca faça PIX só com base em mensagem escrita.
  • Combine com a família uma palavra de segurança secreta.

O que fazer se você pagou

  1. Ligue ao banco e peça o MED (devolução do PIX).
  2. Denuncie o número no próprio WhatsApp (Dados do contato → Denunciar).
  3. Registre um Boletim de Ocorrência e avise a família.
