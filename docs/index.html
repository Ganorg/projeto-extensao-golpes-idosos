As estratégias mais comuns dos golpes

Muitos golpes utilizam estratégias semelhantes para incentivar decisões rápidas. Conhecer essas estratégias ajuda a identificar situações de risco. Fique atento quando a mensagem provocar:

  • Pressa: "faça agora ou você perde", "sua conta será bloqueada hoje".
  • Medo: "sua conta foi invadida", "há uma dívida em seu nome".
  • Oferta boa demais: "você ganhou um prêmio", "aposentadoria extra".

Regra de ouro

Antes de clicar, pagar ou informar qualquer dado: pare, respire e confirme por outro caminho — ligue você mesmo para o banco ou para o parente, usando um número que você já tem anotado.
